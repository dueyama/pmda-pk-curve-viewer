## 近似の補正と限界

従来の実装は `ka > ke` だけを探索し、Tmaxが `1/ke` 以上なら `ka=ke×1.001` に置き換えていた。100mgのkeは0.866434/hで `1/ke=1.154156h`、Tmax1.4hはこの範囲に入らない。従来の連続曲線のピークは1.153579h・1.693553μg/mLとなり、表のTmax・Cmaxとずれていた。200mgでも1.528493h・3.579006μg/mLのピークとなっていた。

今回、出典確認済みのメイアクトの2候補だけ `allowSlowAbsorption` を付け、ka<keの数学的解も探索する。半減期からのke、Tmaxからのka、Cmaxでのピーク補正、反復曲線の加算という構成は維持する。通常の既存候補は従来の近似を保持する。ka=keの極限も処理し、非正・非有限の入力値を拒否する。

|参考曲線|ke (/h)|推定ka (/h)|連続曲線のピーク|0.5h間隔の描画ピーク (μg/mL)|近似曲線の積分AUC∞ (μg・h/mL)|実測参照AUC∞|
|---|---:|---:|---|---:|---:|---:|
|100mg|0.866434|0.581086|1.4h・1.66μg/mL|1.656017|6.444290|3.67|
|200mg|0.653912|0.372371|2.0h・3.44μg/mL|3.440000|19.454495|10.02|

**この補正はピーク形状の近似であり、実測の終末半減期やAUCを同時再現できない。** ka<keでは曲線後半が表の半減期より緩やかになる。推定kaは実測速度定数ではない。AUCは補正に使わない。グラフ付近に「ピーク値・時刻に合わせた教育用近似で、曝露量（AUC）は再現しません」と表示し、表のAUCは「実測参照」と明示した。モデルの計算AUCはUIに曝露量として表示しない。用量比例・反復加算も概算仮定で、個人予測ではない。

## 検証結果

- `PMDA_MEIACT_ZIP=/tmp/drag-meiact.zip npm test`: 8件成功。実ZIP、100/200mgの独立性、単位、出典条件、連続ピークと前後の勾配、非負有限性、15回の反復加算、倍率、分/日の換算、ka=ke極限、不正入力、既存近似の維持を検証。
- 通常の `npm test` はネットワークに接続しない。実ZIPの試験だけ環境変数がないとスキップする。Node.js 22.18以降の型除去とregisterHooksを使う。今回の実行版はNode.js 26.10.0。
- `npm run lint`、`npm run build`（内蔵の型検査を含む）、`git diff --check`: 成功。原設定の `npx tsc --noEmit` は既存.nextに再出現する `cache-life.d 2.ts` 等の生成複製で重複定義エラーになる。ソースや本番用tsconfigを変更せず、この生成複製の `* 2.ts` / `* 3.ts` だけを除外する一時設定 `/tmp/drag-typecheck.json` を使った `npx tsc --noEmit --project /tmp/drag-typecheck.json` は成功。原設定での独立型検査の失敗を解消済みとは扱わない。
- `http://127.0.0.1:3107/`: HTTP 200、main・追加カード・既存の医療安全コピーを確認。`/api/parse-pmda` は実PMDA URLでHTTP 200、100/200mgの値と補足条件を返すことを確認。これらはHTML/APIの確認で、ブラウザ動作確認の代わりとは扱わない。
- Codex内蔵ブラウザは `Browser is not available: iab`、`listBrowsers=[]`。共通AGENTSの「内蔵ブラウザが使えない場合は、必要なブラウザ操作だけを保留」に従い、PC/スマホの見た目・実操作・ブラウザコンソール・エラーオーバーレイは未検証。
- μg/mLで小さな値が出るグラフの縦軸は、表示上限が10未満なら小数2桁で表示し、異なる目盛りが同じ整数に丸められることを避けた。計算点列は変更しない。
